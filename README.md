一个面向 Windows 11、广工大学城校区 `gdut` 无线网络的联网小工具。程序窗口名称为“广工自动联网小工具”。

## 获取与使用

在本仓库的 [Releases](https://github.com/mogavin68/gdut-auto-connect/releases) 下载 `GdutNetwork.exe`。Windows x64 自包含版本无需单独安装 .NET SDK。

1. 运行程序，打开“账号与设置”。
2. 在本机窗口输入自己的校园网账号密码，检查选项并保存。
3. 回到主窗口点击“继续自动恢复”。保存设置本身不会立即提交登录。
4. 关闭窗口会收起到托盘；彻底停止请从托盘选择“退出”。

**重要选项：新计费周期自动确认默认开启，可能触发新周期计费，可在设置中关闭。** 关闭后，遇到该确认会暂停并提醒。

HTTPS 无法正常验证时，只有允许官方 HTTP 登录才会提交凭据；不绕过证书校验。密码保存到当前用户的 Windows 凭据管理器。

## 功能

- 正常时每 60 秒检测；检测到故障后立即恢复，失败后每 60 秒重试。
- 检查 `10.0.3.2` 和 `9.9.9.9` 两个入口，每轮最多提交一次认证。
- 账号密码本机录入、托盘控制、暂停状态跨重启保留、可选登录 Windows 后后台启动。
- 密码错误、验证码、账号异常或未知认证模式时暂停提醒。
- 页面显示已登录但外网不可达时保持会话，不自动注销。
- 当前其他 Wi-Fi 探测成功时保持连接；故障证据不足时不贸然切换。
- 能识别的主动断开及关闭无线电会暂停；无法判断断开原因时按意外掉线尝试恢复。

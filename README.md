一个面向 Windows 11、广工大学城校区 `gdut` 无线网络的联网小工具。程序窗口名称为“广工自动联网小工具”。

## 获取与使用

在本仓库的 [Releases](https://github.com/mogavin68/gdut-auto-connect/releases) 下载 `GdutNetwork.exe`。Windows x64 自包含版本无需单独安装 .NET SDK；余量与缴费功能需要 Microsoft Edge WebView2 Runtime。

1. 运行程序，打开“账号与设置”。
2. 在本机窗口输入自己的校园网账号密码，检查选项并保存。
3. 回到主窗口点击“继续自动恢复”。保存设置本身不会立即提交登录。
4. 关闭窗口会收起到托盘；彻底停止请从托盘选择“退出”。

**重要选项：新计费周期自动确认默认开启，可能触发新周期计费，可在设置中关闭。** 关闭后，遇到该确认会暂停并提醒。

HTTPS 无法正常验证时，只有允许官方 HTTP 登录才会提交凭据；不绕过证书校验。密码保存到当前用户的 Windows 凭据管理器。

## 功能

- 正常时每 60 秒检测；检测到故障后立即恢复，失败后每 60 秒重试。
- 检查 `10.0.3.2` 和 `9.9.9.9` 两个入口，每轮最多提交一次认证。
- 账号密码本机录入、托盘控制、暂停状态跨重启保留、“开机自启动”复选框。
- 原生“余量与缴费”界面：自动登录自助服务，分别显示“账号剩余月数”和“还没使用赠送月数”，选择月份并读取官网报价，用户确认后生成订单、显示官方付款码和订单号。保留官方页面作为备用。
- 充值不会进入每分钟的联网重试；付款由用户扫码完成，支付结果以官网为准。
- “充值记录（近半年）”按北京时间展示从查询当天向前六个月、含起止日期的官网充值明细，支持刷新和官网核对；记录仅在当前窗口内存显示。
- 密码错误、验证码、账号异常或未知认证模式时暂停提醒。
- 页面显示已登录但外网不可达时保持会话，不自动注销。
- 当前其他 Wi-Fi 探测成功时保持连接；故障证据不足时不贸然切换。
- 能识别的主动断开及关闭无线电会暂停；无法判断断开原因时按意外掉线尝试恢复。

- “检查更新”读取公开正式版，下载并验证 SHA-256、大小及产品版本，确认后替换重启；保留旧版备份，失败时尝试恢复。详见 [更新与发布](docs/v0.4-更新与发布.md)。

## 从源码构建

```powershell
.\prepare-sdk.ps1
.\build.ps1
.\test.ps1
.\publish.ps1
```

SDK 为项目内的 .NET 10 SDK，下载后校验微软官方 SHA-512；不修改系统 PATH。发布结果在 `app/GdutNetwork.exe`，运行时包从官方 nuget.org 获取。

首次构建从官方 NuGet 下载依赖，缓存齐全时可使用 `.\build.ps1 -Offline`。第三方组件许可见 [THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt)。

源码分为 `GdutNetwork.Core`（状态与协议）、`GdutNetwork.Windows`（Windows 接口）、`GdutNetwork.App`（操作界面），测试位于 `tests/`。

封面和图标通过内置 ImageGen 生成，提示词见 [视觉素材说明](assets/DESIGN.md)。

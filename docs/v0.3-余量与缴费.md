# v0.3.0：开机自启动、套餐余量和自助缴费

AI 生成，不会对本项目进行维护。此工具不是广东工业大学官方软件。

## 使用

1. “账号与设置”提供“开机自启动（登录 Windows 后在托盘后台运行）”复选框。保存时修改当前用户的 Windows Run 项，不需要管理员权限。该选项决定登录后启动程序，自动恢复是否开启仍由原有的暂停状态决定。
2. “余量与缴费”使用工具已保存的校园网凭据，通过官网前端完成一次 HTTPS 登录。密码不会交给支付平台。需要验证码或登录被拒绝时停止自动提交，可在“官方页面”手动处理。
3. 原生界面分别展示官网“账号剩余月数”和“还没使用赠送月数”。这两个字段按原义显示，不推断彼此是否包含，不相加。字段缺失、格式变化或重复字段冲突时显示待确认，不将未知显示为 0。
4. 月份列表、金额来自当前官网表单。选择月份会触发官网自己的价格计算；不硬编码套餐价格和赠送规则。
5. 点击“生成充值订单”后核对充值账号、月份及金额。提交前再次核对官网当前表单、目标地址、账号、月份与金额；任一变化就停止。
6. 订单生成后，工具在广工统一支付页面请求微信付款码，原生显示二维码、自助服务订单号与微信支付订单号。付款由用户扫码完成。扫码前核对微信显示的收款方与金额。
7. “在官方页面操作”可打开当前支付窗口，处理支付状态查询、付款码刷新等。支付后“刷新余量”重新查询官网。该按钮不会声明已经支付成功，最终结果以官方系统为准。

## 会话与重复操作

- 网络恢复的 60 秒定时器不会发起充值。自助服务自己的定时器只读取当前页面，不会自动重试登录或充值。
- 一次窗口会话只允许从原生按钮提交一笔充值请求。结果不明时不自动补单。
- 原生界面只在订单金额与已确认报价一致时请求、显示付款码；官方标记二维码过期后清除原生二维码。
- 关闭缴费窗口会结束它拥有的浏览器会话。官网可能不允许在新会话恢复未支付订单。再次下单前应先核对官方记录；已扣款请勿重复缴费。
- 不保存或回放付款二维码，不保存支付访问链接，不操作用户微信、不填写银行或支付密码。

## 数据与边界

仅允许顶层导航到已核验的 HTTPS 主机 `selfmanager.gdut.edu.cn` 和 `tyzf.gdut.edu.cn`，自动填写凭据仅限前者的官方登录表单。正常验证证书；不放行 HTTP，不忽略证书错误。使用本工具独立的 WebView2 InPrivate 会话，不读取外部浏览器配置、密码或 Cookie。仅 WebView2 自身的运行文件位于当前用户 LocalAppData；源码目录不保存账户数据。

不导出或记录账号密码、会话 Cookie、充值订单、付款码或支付链接。对外备份不含测试时的页面抓取、个人截图、运行日志与配置。第三方组件许可见 `THIRD-PARTY-NOTICES.txt`。

## 验证记录与限制

- 原有 49 项核心测试、14 项 Windows 模拟测试保持通过。
- 新增 10 项解析／来源／验证码测试和 13 项实际 WebView2 引擎的合成页面测试，覆盖月份选择与报价、账号或金额变化时禁止提交、非官方来源拦截、订单字段、二维码过期状态。
- 已在本机用保存的凭据验证官网前端自动登录、两个余量字段、12 个可选月份及报价；在用户授权的待支付订单上读取了官方订单号和真实付款二维码。
- 真实测试没有扫码付款；付款到账、扣款对账及充值后赠送月份变化尚未实测。断网恢复的历史端到端验收状态没有因本次自助服务测试而改变。
- 官方页面结构、认证或支付方式发生变化时，原生适配可能停止工作，可切换到官方页面核对。

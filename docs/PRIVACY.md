# 备份的数据范围

本备份按文件允许清单重新组装，不上传原开发目录及其历史。

包含：源代码、虚构测试、构建脚本、通用说明、AI 生成的封面与图标。EXE 从这份代码重新构建，禁用调试符号并将编译路径映射为通用路径。

排除：`work/`、`app/`、`bin/`、`obj/`、SDK 缓存、设置 JSON、凭据库、日志、诊断报告、进程信息、真实网络截图、门户抓取页面、浏览器授权截图与旧 Git 历史。

程序无预置使用者账号。运行后需在本机设置窗口配置凭据。学校固定认证入口属于程序配置；测试中的文档地址和虚构密码不代表任何使用者。

## 运行时保存内容

- 当前用户 Windows 凭据管理器：`GDUTAutoNetwork/UniversityTown/v1`。
- 非敏感设置：`%LOCALAPPDATA%/GDUTAutoNetwork/settings.json`。
- 登录后启动选项保存时，仅设置当前用户的 `GDUTAutoNetwork` 启动项。
- 自助服务使用本工具独立的 WebView2 InPrivate 会话，不读取外部浏览器 Cookie 或密码；订单、二维码和支付链接只在当前窗口会话使用，不写入备份。WebView2 运行文件放在当前用户 LocalAppData，关闭缴费窗口会结束它的会话。
- 半年充值记录使用本工具自己的官网会话进行只读查询，仅在缴费窗口内存中展示，不保存明细文件，不导出或上传备份。

移除前可在设置中取消登录后启动并保存、删除已保存凭据，然后从托盘退出。

# v0.4.0：检查更新与发布

AI 生成，不会对本项目进行维护。不是广东工业大学官方软件。

主窗口和托盘菜单提供“检查更新”。点击后读取固定公开仓库 `mogavin68/gdut-auto-connect` 的最新正式 Release，显示版本说明，可下载新版。草稿和预发布不参与更新。仅在用户点击时查询，没有自动后台轮询。

下载只使用 HTTPS 和公开地址，不携带 GitHub 令牌、校园网凭据、设置、充值记录或会话 Cookie。校验 GitHub 公布的 SHA-256、文件大小、产品标识和程序版本；来源、跳转、格式或校验不符时停止。可取消下载，网络中断不会替换程序。

下载完成后需点击“安装并重启”，并确认结束打开的缴费会话。先核对付款，再确认安装。更新器等待原进程退出，不强制终止进程；在安装目录内暂存并核验新文件，保留唯一命名的 `.previous` 旧版备份，再替换及启动。替换或启动失败时尝试恢复旧版。账号凭据与设置位于原有用户目录，不迁移或清空。

更新缓存位于 `%LOCALAPPDATA%/GDUTAutoNetwork/updates/`。成功更新后仅清理已完成会话的已知缓存文件；旧版 `.previous` 备份保留在安装目录，可在确认新版正常后自行删除。安装目录无写权限、包含链接或存在外置程序组件时可能需要从发布页手动更新。不会提升管理员权限或绕过证书验证。

维护流程：每次源码变更先提交推送私密开发仓库；完成构建、测试、个人数据检查和 Release 校验后，再把同一提交同步到公开仓库。正式 EXE 从经过筛选的源码构建，关闭调试符号并映射构建路径。公开范围不包括运行数据和本机工作缓存。

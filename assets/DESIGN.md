# Visual assets

Both raster assets were created with the built-in ImageGen tool. They use a generic campus/network motif, without an official university emblem or user information. The ICO is a technical, multi-resolution conversion of the generated PNG (16/32/48/64/128/256 pixels).

## Cover prompt

Use case: ads-marketing. Asset type: a polished horizontal software repository cover banner, approximately 16:9, for a small unofficial Windows campus-network reconnection utility.
Primary request: Design a clean, elegant cover for the Chinese software named "广工自动联网小工具".
Scene and style: refined flat/soft 3D editorial technology illustration, calm off-white background, restrained blue and teal accents matching a Windows network utility. A friendly central Wi-Fi signal motif connected with a circular reconnect arrow and a very subtle abstract campus skyline. Clear generous typography, professional and approachable, strong hierarchy and ample whitespace, crisp readable Chinese.
Text (verbatim): main title "广工自动联网小工具"; small subtitle "校园网检测 · 自动重连 · 托盘运行"; small visible footer "AI 生成 · 本项目不维护"; a modest label "非官方工具".
Constraints: Only those texts, spell Chinese accurately. No real university crest, seal, official logo or suggestion of official endorsement. No usernames, email addresses, accounts, passwords, QR codes, IP addresses, screenshots or private information. No exaggerated guarantees, no busy cyberpunk effects, no other logos, no watermark. Opaque background.

## Icon prompt

Use case: logo-brand. Asset type: a Windows desktop application icon for an unofficial Chinese campus Wi-Fi auto-reconnect utility.
Create a single beautifully polished icon, square composition, centered with ample transparent outer padding, no text at all. A deep royal-blue rounded square tile with gently rounded corners and subtle soft depth. Inside, a very clear white Wi-Fi signal above a white dot, surrounded by a clean mint-teal circular reconnect arrow. Restrained premium flat/soft-3D treatment, strong contrast, simple bold forms readable at 16x16 and 32x32, balanced symmetry, crisp edges. Match an understated blue-and-teal Windows networking utility aesthetic. No university crests, no official logos, no initials, no letters, no numbers, no badges, no watermarks, no small details, no extra objects. Transparent background outside the blue rounded square tile; do not depict a checkerboard.
